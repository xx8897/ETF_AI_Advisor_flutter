# 資料來源的艱難探索

> 這是專案最曲折的故事。四種外部資料來源，全部失敗，最終回到一個 Excel 檔案。

## 為什麼資料來源這麼重要

RAG 的品質取決於向量資料庫的品質，向量資料庫的品質取決於原始數據的品質。如果 ETF 的成分股數據不完整，AI 檢索出來的結果就會偏離，推薦就會出錯。

專案需要的數據：

| 數據 | 為什麼需要 |
|------|-----------|
| ETF 完整列表 | 搜尋的基礎集合 |
| ETF 名稱和代碼 | 辨識基礎 |
| 類別/主題 | 主題權重搜尋 |
| 基金規模 | 過濾小型 ETF |
| Beta 值 | 量化篩選 |
| 夏普值 | 量化篩選 |
| 年化殖利率 | 風險偏好搜尋 |
| 配息頻率 | 風險偏好搜尋 |
| 成分股和持股比例 | 投資組合總覽 |

**成分股是最關鍵的數據**——它讓 AI 能告訴使用者「你推薦的這 4 檔 ETF 加起來，台積電佔了 35%」。

## 第一次嘗試：FinMind API v4

**期待**：FinMind 是台灣金融數據 API，應該有完整的 ETF 數據。

**現實**：
- ✅ 有每日股價和歷史配息
- ❌ 沒有 ETF 完整列表（只有個別查詢）
- ❌ 沒有成分股資料
- ❌ 沒有費用率

FinMind 可以提供價格和配息，但不能提供成分股。沒有成分股，投資組合總覽功能就無法實現。

## 第二次嘗試：TWSE OpenAPI

**期待**：台灣證券交易所的官方 API 應該有最完整的數據。

**現實**：
- ✅ 有 ETF 基本資料
- ⚠️ 成分股 API 端點存在但數據不完整
- ❌ 沒有量化指標（Beta、夏普值）

TWSE 是最接近的，但成分股數據的缺失意味著我們無法計算投資組合的加權持股。

## 第三次嘗試：網頁爬蟲

**期待**：Goodinfo、MoneyDJ、Wantgoo、MacroMicro 這些網站有完整的 ETF 數據。

**現實**：
- ❌ 全部採用動態載入技術（JavaScript rendering），簡單的 HTTP 請求抓不到數據
- ❌ 全部有反爬蟲機制（Rate limiting、CAPTCHA、IP 封鎖）
- ❌ 資料格式不統一，每個網站的 HTML 結構不同
- ❌ 維護成本極高——網站改版就要重寫爬蟲

團隊嘗試了四個網站，全部失敗。不是技術上做不到（Selenium + Puppeteer 可以繞過動態載入），而是維護成本太高、穩定性太低。

## 第四次嘗試：yfinance

**期待**：Yahoo Finance 的 Python 套件應該有國際市場的 ETF 數據。

**現實**：
- ✅ 有基本的 ETF 資訊
- ❌ 台灣市場的深度資料（成分股、持股比例）嚴重不足
- ❌ 很多台灣 ETF 的數據是空的或不準確的

yfinance 對美國市場很好，對台灣市場不夠。

## 第五次嘗試：使用者提供的 Excel

**轉折點**：在窮盡了所有外部資料獲取方案後，專案迎來了最重要的決策——**由使用者提供一個單一、完整、權威的 `etf.xlsx` 檔案**。

這個 Excel 包含了專案需要的所有數據：
- ETF 代碼、名稱、類別
- 基金規模、科技占比
- Beta 值、夏普值
- 年化殖利率、配息頻率
- **前十大持股和比例**（最關鍵的數據）
- **1 年報酬率**

**為什麼這是正確的選擇**：

1. **數據品質完全可控** — 使用者可以驗證和修正每一個值
2. **沒有 API 限流** — 本地檔案，不限次數
3. **沒有爬蟲反制** — 不依賴任何外部網站
4. **成分股完整** — 使用者可以提供最準確的成分股數據
5. **更新簡單** — 換一個新的 Excel 檔案就好

**為什麼這不是完美的選擇**：

1. **手動更新** — 數據不會自動更新
2. **版本控制困難** — Excel 檔案的 diff 不如代碼清楚
3. **擴展性有限** — 如果 ETF 數量增加到幾千檔，Excel 會變得很大

但對於台灣市場的 200+ 檔 ETF，Excel 是完全可行的。

## 影響

資料來源的選擇影響了整個架構：

| 決策 | 影響 |
|------|------|
| 單一 Excel | 不需要 API 限流處理、不需要爬蟲維護 |
| 單一 Excel | `portfolio_holdings` 和 `etf_details` 路由直接讀 Excel |
| 單一 Excel | 每次請求都讀取 Excel（無快取）|
| 單一 Excel | 數據更新需要手動替換檔案 + 重建向量資料庫 |

這是務實的選擇——犧牲了自動更新，換來了數據品質和架構簡潔性。
